# רומא: מדריך טיול

אפליקציית ווב קטנה: מאגר מקומות ומסעדות ברומא ובפירנצה, מידע שימושי (מטרו, טיפים, משפטים באיטלקית) ורשימות.
אין שרת ואין מסד נתונים. זה אתר סטטי שנשמר על מסך הבית ועובד גם בלי אינטרנט.

## פרטיות: מה יש באתר ומה לא

- **באתר (הריפו הזה, ציבורי):** רק מדריך כללי. אין תאריכים, מלון, טיסות, לו״ז, הזמנות או הוצאות.
- **בקישור הפרטי בלבד:** כל פרטי הטיול. הם נמצאים אחרי ה-`#` בקישור, ודפדפנים אף פעם לא שולחים את החלק הזה לשרת. אחרי הטעינה הם נשמרים רק בטלפון (localStorage).
- את הקישור שולחים רק בצ׳אט פרטי.

## איך מתקינים בטלפון

1. פותחים את כתובת האתר בספארי ← שיתוף ← **הוסף למסך הבית**.
2. פותחים את האפליקציה מהאייקון, ובמסך הבית שלה מדביקים את הקישור הפרטי.
3. מאז היא עובדת גם בלי קליטה.

## עדכון הטיול

מקבלים קישור חדש ומדביקים אותו באפליקציה (״מידע״ ← ״קישור הטיול וסנכרון״). קישור חדש תמיד גובר על ישן, והסימונים האישיים (וי, הערות, מועדפים) נשארים.
כדי להעביר את הכל לטלפון השני: ״שליחת קישור סנכרון״, ובטלפון השני מדביקים.

לבניית קישור מקובץ JSON, או לפענוח קישור קיים לעריכה:

```
node tools/trip-link.mjs decode '<link>' > private/trip.json
node tools/trip-link.mjs encode private/trip.json
```

התיקייה `private/` לא נכנסת לגיט.

## הפעלת GitHub Pages (פעם אחת)

Settings ← Pages ← Build and deployment ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save.

## מבנה

```
index.html            מעטפת האפליקציה
css/style.css         עיצוב (כולל מצב כהה)
js/guide.js           המדריך הכללי (מקומות, טיפים, משפטים)
js/app.js             מסכים, ניווט, שמירה מקומית וטעינת הקישור
sw.js                 עבודה בלי אינטרנט
tools/trip-link.mjs   בנייה ופענוח של הקישור הפרטי
```

להרצה מקומית: `python3 -m http.server` ואז `http://localhost:8000`.
לבדיקת מסך ״היום״ בתאריך אחר: `?date=YYYY-MM-DD&time=HH:MM`.
